# 🎨 Archetype UI — UI Design Styles Encyclopedia & Lab

Ek comprehensive aur fully interactive website jaha duniya ke saare major UI design styles/paradigms categories ke hisaab se live interactive examples, code inspector, aur morphing playground ke saath available hain.

---

## 🌟 Included Design Styles & Categories

| # | Style Paradigm | Core Characteristics & CSS Secrets | Best Use Cases |

## 🚀 Key Features

1. **The Chameleon Lab (Live Style Morpher):**
   - Kisi bhi component (User Profile Card, SaaS Pricing Tier, ya Media Player) ko select karke kisi bhi UI style pe click karo — component instantly live render aur morph ho jayega!
   - 4 alag Canvas backgrounds (Mesh Gradient, Pitch Dark, Clean Light, Tech Grid) me test karne ki suvidha.

2. **Interactive Live Components:**
   - Har ek style ke card me clickable buttons, real-time working toggle switches, inputs, aur status badges hain.

3. **Inspect & Copy Code Drawer:**
   - Har style ka direct **HTML Snippet** aur **CSS Rules** 1-click copy karne ke liye available hai.
   - **Color Palette Swatches:** Click karke exact HEX color code copy karein.
   - **Secret Sauce & Rules:** Har style ki design theory, Best Use Cases aur "When to Avoid" guidelines.

4. **Category Filter & Real-Time Search:**
   - Clean, Bold, Modern, 3D, Dark, Retro tags ke through filter karein ya search bar se search karein.

5. **Design Comparison Matrix:**
   - Saare styles ka tabular comparison (Border rules, Shadow mechanics, Vibe, and Best Fit).

## 💻 How to Run

Website ko run karne ke liye terminal me ye command chalayein:

```bash
python server.py
```

Server start hone ke baad browser me open karein:
👉 **`http://127.0.0.1:8000`**

*(Ya fir direct `index.html` ko kisi bhi browser me open kar sakte hain)*
